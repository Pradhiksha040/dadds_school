Getting Started

Overview

This is a PHP MVC-based NGO Management System with a built-in one-time installation wizard. Once installed, it manages members, donors, donations, campaigns, projects, careers, CMS pages, finance reports, and more.

PropertyValue
ArchitectureCustom PHP MVC (no framework)
Front Controllerindex.php (root) → public/index.php
DatabaseMySQL / MariaDB via PDO
Config.env file in project root
AssetsServed from public/ directory
Installerinstall.php — auto-disabled after setup

Installation

Step-by-Step Installation Guide

1

Upload the project files

Upload the entire project folder to your hosting environment:

Localhost: Place inside htdocs/ (XAMPP) or www/ (WAMP)
cPanel / Hostinger: Upload to public_html/ or any subdirectory inside it
Subdomain: Upload to the subdomain's document root folder

2

Create a MySQL database

In cPanel → MySQL Databases, create a new empty database and a database user. Assign full privileges to the user on the database. Note down: host, database name, username, password.

3

Verify folder permissions

The project root directory must be writable by PHP so the installer can create the .env file.

On Linux / cPanel run: chmod 755 /path/to/project
Storage folder: chmod 775 storage/uploads/

4

Open the installer in browser

Navigate to your site URL in a browser. If .env does not exist, the system automatically redirects to the installer:

http://localhost/production_build/install.php
https://yourdomain.com/install.php
https://app.yourdomain.com/install.php

5

Step 1 — Database Configuration

Fill in the database connection details. The Application URL is auto-detected but verify it is correct. Click Continue. The wizard tests the database connection before proceeding.

6

Step 2 — Administrator Account

Enter the email and password for the super admin account. Password must be at least 8 characters. Re-enter to confirm. Click Complete Setup.

7

Installation Complete

The wizard creates the .env file and runs all database migrations automatically. You will see two buttons — Visit Site and Admin Login. After this, install.php returns a 404 for security.

8

Log in to Admin Panel

Go to https://yourdomain.com/auth and log in with the email and password you set in Step 2.

Tip: For security, delete or rename install.php from the server after installation is complete.

Installation

.env File

The installer creates this file in the project root automatically. You can also create it manually.

# Application
APP_NAME="NGO Management System"
APP_URL=http://yourdomain.com/
APP_KEY=a8f3c9d1e2b4...  # auto-generated 32-char hex

# Database
DB_HOST=localhost
DB_NAME=ngo_database
DB_USER=root
DB_PASS=your_password
Important: APP_URL is used as BASE_URL throughout the application. It must end with a trailing slash / and must exactly match the URL where the app is hosted.
